# Planilhas modelo

Enviar para a Formigueiro Metais preencher (prazo: 22/09).

| Arquivo | O que é |
| --- | --- |
| `materias-primas.csv` | materiais disponíveis, com composição, custo e rendimento |
| `ligas.csv` | ligas produzidas, com faixa mínima e máxima por elemento |
| `corridas-historicas.csv` | corridas passadas: análise inicial, adições e análise final |

Os valores que estão nos arquivos são **exemplos fictícios** feitos pelo time,
só para mostrar o formato. Substituir pelos dados reais.

As corridas históricas viram casos de teste em `engine/tests/casos_reais/`
(US-08) e alimentam a calibração (US-17). Precisamos de no mínimo 15.
